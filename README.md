# 🐱 Flying Cat

A simple Scratch game where the player controls a flying cat
using the Space key while avoiding obstacles.

## 🎮 How to Play

- Press Space to make the cat fly upward.
- Avoid the obstacles.
- The score increases as you continue playing.
- The game resets when the cat hits an obstacle or the edge.

## 🛠️ Built With

- Scratch
